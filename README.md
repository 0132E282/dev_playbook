Welcome to **Dev Playbook** - a curated collection of fine-tuned "Skills" specifically designed for AI Coding Assistants (Claude, Antigravity, ChatGPT). This repository helps transform standard AI assistants into true **Senior Software Architects** for your project.

---

## 🌟 Why Use These Skills?

Providing strict context and rules to AI is the key to receiving high-quality code. **Dev Playbook** standardizes the workflow through:
- **Strict Standards**: Enforcing SOLID, DRY, KISS, and YAGNI.
- **Architectural Thinking**: Beyond just writing code, the AI provides System Design advice and Security Audits.
- **Automation**: Includes supporting scripts like `automator.py` for cross-platform automated testing.

---

## 🛠 Expert Skills List

The collection is categorized into 4 core capability groups in the [`skills/`](./skills) directory:

### 1. 🔍 [Coding Reviewer](./skills/coding-reviewer)
Upgrade your AI into a high-level **Code Auditor**.
- **Focus**: Security (OWASP), Performance (Big O), Naming Conventions.
- **Output**: Detailed comparison tables between 🔴 Current vs 🟢 Proposed code.
- **References**: Naming standards, formatting rules, and security checklists.

### 2. 💻 [Coding Assistant](./skills/coding-assistant)
Establish the identity and programming style for your AI.
- **Identity**: Acts as a Senior Software Architect.
- **Rules**: Strict **No Abbreviations** policy, robust error handling, naming discipline.
- **Templates**: Mermaid diagrams for system architecture, standardized PR templates.

### 3. 🧪 [Tester Agent](./skills/tester-agent)
A specialist in **Clean Testing**.
- **Capabilities**: Writes high-quality Unit, Integration, and E2E Tests.
- **Tooling**: Includes `automator.py` to automatically detect and run tests (Laravel, React, Node, Python, .NET).
- **Standards**: Adheres to the 12 Golden Rules of testing.

### 4. 📝 [Summary Agent](./skills/summary-agent)
An assistant for technical summarization and technical writing.
- **Tasks**: Overall project overviews, explaining complex file logic, summarizing changes between branches/PRs.
- **Benefits**: Significantly speeds up developer onboarding.

## 🚀 Integration Guide

To "upgrade" your AI assistant, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/0132E282/dev_playbook.git
   ```
2. **Copy to your project**: Move the desired skill folders into your AI assistant's configuration directory (e.g., `.claude/skills/`).
3. **Activate**: Instruct the AI assistant to read the `SKILL.md` file in the corresponding directory.

---

## 📐 Core Standards

Every piece of source code generated by these skills must pass the following checklist:
- [ ] **SRP**: Every class/function does only one thing.
- [ ] **Naming**: Clear variable names, no abbreviations (e.g., `user` instead of `usr`).
- [ ] **Silence**: Never suppress errors (No silent catch blocks).
- [ ] **Documentation**: Explain *Why* (business context), not just *What* (logic).
